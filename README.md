# 电路分析 Python 工具集

面向电气工程专业学生的 Python 实战脚本合集：从基础电路计算，到交流电分析、谐波 FFT、节点电压法求解，再到用电量预测与实验报告生成。

作者：东北电力大学 · 电气工程 · 大一

## 环境准备

需要 **Python 3.8+**。

```bash
pip install -r requirements.txt
```

## 脚本一览

| 文件 | 做什么 | 主要用到的库 |
| --- | --- | --- |
| `02_RC充放电曲线.py` | 画 RC 一阶电路的充放电曲线 | matplotlib / numpy |
| `03_多电阻对比.py` | 不同阻值下的响应对比图 | matplotlib / numpy |
| `04_电阻串并联计算器.py` | 串并联等效电阻计算 | 标准库 |
| `05_交流电波形与相量图.py` | 正弦交流电波形 + 相量图 | matplotlib / numpy |
| `06_实验数据伏安特性.py` | 读取实验数据并拟合伏安特性曲线 | matplotlib / numpy / csv |
| `07_节点电压法.py` | 用节点电压法求解电路（矩阵求解） | numpy |
| `08_数学建模工具箱.py` | 线性规划求解（scipy.optimize.linprog） | numpy / scipy |
| `09_预测模型.py` | 用电量时间序列预测（ARIMA） | numpy / matplotlib / statsmodels |
| `10_谐波分析FFT.py` | 对信号做 FFT，分析谐波分量 | numpy / matplotlib |
| `12_真题解答.py` | 线性规划真题求解 | numpy / scipy |
| `13_LED限流电阻.py` | LED 限流电阻选型计算 | 标准库 |

## 其他文件

| 文件 | 说明 |
| --- | --- |
| `元器件速查表.html` | 常用元器件参数速查（浏览器直接打开） |
| `11_实验报告模板.tex` | LaTeX 实验报告模板（配合 TeX 环境使用） |
| `*.png` | 各脚本运行后生成的图表 |

## 运行示例

```bash
python 04_电阻串并联计算器.py
python 10_谐波分析FFT.py
```

带绘图的脚本运行后会弹出窗口或生成 PNG。

## 学习路线建议

1. 先跑 `04`、`13` —— 纯计算，不需要装第三方库
2. 再跑 `02`、`03`、`05` —— 学会用 matplotlib 画图
3. 然后 `07`、`10` —— 真正用到线性代数和信号处理
4. 最后 `08`、`09`、`12` —— 数学建模与预测
